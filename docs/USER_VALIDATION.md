# 用户研究、任务试用与反馈模板

状态：计划与空白模板，尚未开展访谈或用户试用。

## 招募与范围

先招募 3–5 名金融、数据或产品方向同学作为代理用户，记录是否有风险审核经验。能邀请目标岗位从业者则单独标记。代理用户试用不能写成银行员工试点或企业内部推广。

## 访谈问题

1. 面对一笔风险交易，首先核对什么？
2. 哪些证据足以支持初步摘要，缺什么就不能判断？
3. 如何决定下一步调查动作？
4. AI 生成内容有哪些情况会让你拒绝采用？
5. 哪些步骤重复或耗时，哪些错误代价更高？

分别记录原话、观察与研究者推断。没有访谈前，PRD 中的痛点保留“假设”标记。

## 任务与对照

- 每人完成 4–6 个案例，使用不同但难度相近的两组任务。
- 一组查看证据并手工整理摘要；另一组使用 AI 草稿辅助。两组都使用同样的证据界面。
- 一半用户先人工、一半先 AI；避免同一用户重复同一案例造成学习效应。
- 统一任务：提交摘要、说明信息缺口、选择处理状态并记录理由。
- 如使用 Mock，结论仅为工作流/模板辅助的可用性观察，不能当作真实 LLM 效果。
